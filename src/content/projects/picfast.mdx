PicFast 是可一键部署的开源图床，提供易用的管理后台和开放 API，轻松对接上传工具、自动化工作流及各类 AI 应用。部署只需一条 `docker run`，首次启动有初始化向导。上线 5 个月发布 48 个版本，Docker Hub 镜像拉取逾 1.2 万次（截至 2026-09），另有在线演示 [demo.picfast.dev](https://demo.picfast.dev)。

![PicFast 管理后台](/projects/picfast/console.png)

## 核心功能

- **多用户与游客上传** — 用户/分组额度管理，邮箱注册验证
- **六种存储后端** — 本地 / S3 兼容 / 七牛 Kodo / 阿里云 OSS / 腾讯云 COS / WebDAV，后台可切换
- **开放 API** — REST API + API Token，自动生成的 OpenAPI 文档
- **MCP 服务器** — `@picfast/mcp`，AI Agent 直接上传/管理图片
- **CLI 与 VS Code 扩展** — 命令行上传、编辑器内粘贴上传
- **ShareX 集成** — 原生对接常用截图上传工具
- **管理后台** — 主题定制、用户管理、存储配置、审计日志
- **运维友好** — Webhook、OAuth 登录、Prometheus 指标、备份/巡检/恢复 CLI

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Go 1.26, Chi Router, pgx/v5, sqlc, JWT（单二进制，前端产物内嵌） |
| 前端 | React 19, TypeScript, Vite, Tailwind CSS v4 |
| 数据库 | PostgreSQL 16，启动时自动迁移 |
| 部署 | Docker 单容器 + 外挂 PostgreSQL |

当前版本 v0.23.1，GPL-3.0 开源。
