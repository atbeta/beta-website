AgentCast（Cast to your agents）是鸿蒙原生的「桌面 Agent 遥控器」，面向在桌面/服务器上自部署 Agent 的开发者：手机即遥控器，刻意不做 IM、不做端侧 Agent 运行。通过归一化事件协议层对接多种 Agent，协议漂移隔离在适配器层——鸿蒙生态目前尚无同类产品。

![AgentCast 聊天页：流式回复与工具调用卡片](/projects/agentcast/chat.png)

## 核心功能

- **多 Agent 接入** — Hermes 直连、OpenAI 兼容适配器、OpenCode 适配器；OpenClaw 桥接（M2）规划中
- **归一化事件模型** — Profile / Session / Message / ToolCall / Approval / StreamEvent，新增一种 Agent 只需实现一个适配器
- **流式聊天** — SSE 传输，指数退避重连 + 断线增量拉历史
- **人在环路审批** — 允许一次 / 会话内免问 / 始终信任 / 带原因拒绝
- **安全设计** — Ed25519 设备签名配对，Token 存系统密钥库（HUKS AES-GCM），明文不落盘
- **系统整合** — 后台长时任务 + 系统通知触感、桌面服务卡片、上下文用量可视化、会话导出 Markdown

![AgentCast 控制台：多 Agent 实例概览](/projects/agentcast/console-dark.png)

## 技术栈

ArkTS / ArkUI（状态管理 V2），HarmonyOS 5.0+；RelationalStore 本地持久化；SSE / WebSocket / HTTP 三种传输。严格分层「页面 → ViewModel → 领域模型 + 连接层」，纯逻辑抽成零依赖模块用 Node 直跑单测（当前 650+ 用例）。

## 状态

开发中：M1（Hermes 直连 MVP）已完成，M1.5（审批/中断）进行中，M2（OpenClaw 桥接）待启动。暂未开源，计划成熟后上架华为应用市场。
